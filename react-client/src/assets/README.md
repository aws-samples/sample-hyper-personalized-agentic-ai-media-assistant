# Assets Folder

This folder contains static assets used by the application.

## Images
- Logo and branding images
- Background images (currently used in `src/index.css`)
- Icons and other UI assets

## Current Background Image
The background image is currently set in `src/index.css` and references `background_nab_2024.jpg` from this folder.

To change the background image:
1. Replace `background_nab_2024.jpg` with your new image
2. Or update the CSS reference in `src/index.css` to point to your new image file

## Supported Image Formats
- JPG/JPEG
- PNG
- WebP
- SVG
